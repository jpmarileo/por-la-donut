# Donas Patagónicas - Página de Venta

Landing page completa de e-commerce para venta de donas artesanales con carrito funcional. Proyecto ideal para portafolio frontend (HTML, CSS, JavaScript).

## 🌟 Características

- **Diseño moderno y responsive** (mobile first)
- **Carrito de compras** completo con localStorage
- **Interfaz atractiva** con Tailwind CSS
- **Filtro y productos** dinámicos
- **Integración con WhatsApp** para pedidos reales
- **Optimizada para velocidad**

## 🚀 Tecnologías usadas

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript (ES6+)
- Font Awesome icons
- Responsive design
